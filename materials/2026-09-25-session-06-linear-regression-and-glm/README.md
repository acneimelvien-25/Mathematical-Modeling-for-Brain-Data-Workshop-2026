# Session 6: Linear Regression and the General Linear Model

- **Date:** 25 September 2026
- **Time:** To be confirmed
- **Speaker:** Hubert

## Overview

This session moves from relationships between variables to prediction, model fitting, and the general linear model used in brain-data analysis.

## Topics

- correlation and linear relationships;
- simple linear regression;
- least-squares estimation;
- residuals and model fit;
- matrix notation for regression;
- the general linear model as a shared framework;
- connections among regression, t-tests, and ANOVA;
- uses of the GLM in neuroimaging; and
- connections between the GLM and probability.

## Learning outcome

Participants should understand linear regression as a mathematical model connecting predictors to outcomes, express it in matrix form, and recognize the GLM as a general framework for analyzing neural and neuroimaging data.
