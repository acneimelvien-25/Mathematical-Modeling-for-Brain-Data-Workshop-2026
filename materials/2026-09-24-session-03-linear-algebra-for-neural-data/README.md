# Session 3: Linear Algebra for Neural Data Representation

- **Date:** 24 September 2026
- **Time:** 09:00-11:00 UTC
- **Speaker:** Waliy

## Overview

This session develops the linear-algebra intuition needed to represent and compare neural observations such as voltage traces, spike trains, firing rates, population activity, EEG, and fMRI data.

## Topics

- scalars, vectors, matrices, and time series;
- neural responses in high-dimensional spaces;
- vector addition, scalar multiplication, and linear combinations;
- dot products, cosine similarity, norms, and distances;
- correlation, covariance, similarity, synchrony, and connectivity;
- matrices as data tables and transformations;
- matrix-multiplication intuition and linear systems; and
- an introduction to eigenvalues, eigenvectors, and principal component analysis.

## Learning outcome

Participants should be able to interpret neural activity as mathematical objects and reason about patterns, distances, similarities, and transformations in neural data.
