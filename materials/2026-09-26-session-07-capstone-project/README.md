## Overview

The capstone project asks participants to select a mathematical neuroscience model and use it to explain a real biological or cognitive system.

## Suggested project workflow

1. Define a focused biological or cognitive question.
2. Select a model appropriate to the question.
3. Identify the model variables, parameters, and assumptions.
4. Simulate or analyze the model.
5. Interpret the result in biological terms.
6. Discuss limitations and possible extensions.
7. Present the explanation and supporting evidence.

## Learning outcome

Participants should be able to use a mathematical model as an intuitive explanatory framework, connect results to a real system, and communicate assumptions and limitations.
