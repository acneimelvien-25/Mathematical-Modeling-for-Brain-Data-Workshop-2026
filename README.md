# Mathematical Modeling for Brain Data (MAMBA) Workshop 2026

**Theme:** Math for Brain Data: Mathematical Foundation to Neuro-systems

Hosted by the [African Computational Neuroscience Educational Initiative (ACNEI)](https://acnei.org/)

- **Dates:** 23-26 September 2026
- **Format:** Virtual workshop
- **Time zone:** UTC

## Program overview

The MAMBA Workshop introduces the mathematical foundations used to describe, analyze, and model brain data. Across six teaching sessions and a project day, participants will connect biological questions to mathematical ideas from dynamical systems, linear algebra, calculus, probability, regression, and neural modeling.

The workshop is designed for learners from natural, physical, computational, and related sciences. Prior neuroscience or programming experience is helpful but not required; curiosity and a willingness to engage with mathematical ideas are the main prerequisites.

## Learning goals

By the end of the workshop, participants should be able to:

- explain why mathematical and computational models are useful in neuroscience;
- connect biological neuron behavior to simplified mathematical models;
- represent neural data using vectors, matrices, distances, and transformations;
- describe neural dynamics using derivatives, differential equations, equilibria, and stability;
- reason about variability and uncertainty using probability distributions;
- understand linear regression and the general linear model as tools for brain-data analysis; and
- apply a mathematical neuroscience model to a biological or cognitive question.
